# Parkour Dash

A tiny browser-based parkour game built with plain HTML, CSS, and JavaScript.

## How to run

Option 1: open `index.html` directly in your browser.

Option 2: run a local web server from this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Controls

- Move: A / D or Left / Right arrows
- Jump: W / Up arrow / Space
- Restart: R

## Goal

Collect the glowing coins and reach the flag at the end of the level without touching the spikes.

## Files

- `index.html` – page structure
- `style.css` – styling
- `game.js` – gameplay logic
